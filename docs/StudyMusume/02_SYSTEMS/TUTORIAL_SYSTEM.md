# Tutorial System

## 目的

- 初回プレイの5分前後で `このゲームは高瀬エマと一緒に英語を進めて仲良くなるゲーム` だと伝える
- `Home -> 学習 -> クイズ -> 好感度上昇 -> 次の約束` を1セットで必ず体験させる
- 学習を始める心理ハードルより `エマと続けたい` 気持ちを先に作る

## 初回チュートリアルで伝えること

1. 最初から `高瀬エマ` が学習を見てくれる
2. 当面のMVPは `エマ単独ヒロイン` で進む
3. まずは `文法授業` を1回やれば流れが分かる
4. 学習の最後にエマとのやり取りがある
5. 正解や完了で `好感度` が上がる
6. 続けると `次の約束 / 会話 / イベント` が気になってくる

## チュートリアルの原則

- 最初の30秒以内にプレイヤー自身の操作を始めさせる
- 世界観説明を長文で読ませない
- 最初の出会いは `選択画面` より `エマが待っている感覚` を優先する
- 最初の学習は短く、確実に終われる内容にする
- 初回クイズは `1問だけ / 易しめ / 再挑戦しやすい` にする
- 初回で失敗しても気まずくしない

## 体験フロー

### 1. はじめまして画面

- タイトルのあとに短い導入を1枚だけ見せる
- 説明は `英語を続けるほど、あの子との距離が近づく` 程度に絞る
- ここで長い設定説明はしない

### 2. エマとの初回接触

- 放課後の空き教室や自習スペースでエマに声をかけられる
- ここで `英語を見る相手` としての関係を作る
- キャラ選択や比較UIは出さない

### 3. 選択後のホーム着地

- エマの立ち絵を中央に出す
- 一言セリフで `今日ここから始める感` を即返す
- 画面内の主役は `文法授業 START` の1本に絞る
- 補助導線は見せても押させないか、目立たせない

### 4. 最初の文法授業

- 1テーマだけの超短縮版にする
- 体感は `2〜3分以内` に収める
- 学習中にエマの短い反応を1〜2回差し込む
- この段階では `勉強が難しい` より `一緒に進めている感` を優先する

### 5. エマ確認クイズ

- 授業の最後にエマが1問だけ出す
- クイズ文面は学習内容の確認になっていること
- 不正解でも軽いフォローを入れて、再挑戦しやすくする
- 初回は `最後にちゃんと正解して終われる` ことを優先する

### 6. リザルト

- ここで `理解度アップ` と `好感度アップ` を同時に見せる
- 好感度は数字だけでなく、ハートや短いセリフで気持ちよく返す
- エマの褒め方と距離感が最初に見える場面にする

### 7. 次の約束予告

- リザルト直後に `また来てね` で終わらせず、次の接点を1つ置く
- 形式は `放課後に少し話したい`, `次はここまで一緒にやろう`, `明日も待ってる` など
- まだ重いイベントではなく、続けたくなる小さな約束にする

### 8. チュートリアル後ホーム

- Home に戻したとき、エマと次のおすすめ学習を見せる
- `次の約束` と `次に押すボタン` が迷わず分かる状態にする
- ここで初めて通常ループへ渡す

## 画面ごとの必須要素

### 初回ホーム

- エマ立ち絵
- エマの一言セリフ
- `文法授業 START` 大ボタン
- 目立つ補助情報は1つまで

### 初回リザルト

- 学習完了表示
- 理解度アップ
- 好感度アップ
- エマの短い褒めセリフ
- 次の約束予告
- Home に戻る導線

## 演出ルール

- 初回のご褒美は `大きな数値報酬` ではなく `特別に見てもらえた感覚`
- 好感度上昇表示はリザルト内で見せる
- リザルト後に別ポップアップを何枚も重ねない
- エマのセリフは短く、余韻が残る言い方にする
- 初回は機能説明より感情のフックを優先する

## 初回失敗時の扱い

- 初回チュートリアルでは好感度を下げない
- クイズ不正解時はエマが1回だけヒントを出す
- 再挑戦後にクリアできれば、通常どおり好感度を上げる
- `失敗しても嫌われない` 安心を最初に作る

## 実装優先順

1. 初回ホームで `文法授業 START` を主役にする
2. エマとの導入会話を1シーン入れる
3. 初回文法授業の超短縮版を作る
4. 最後に `エマ確認クイズ 1問` を入れる
5. リザルトで `好感度上昇 + 次の約束予告` を見せる
6. チュートリアル後に通常 Home へ戻す

## 完了条件

- 初回5分前後で1ループ終わる
- プレイヤーが `エマと一緒に進めている` 感覚を持てる
- エマの反応を最低2回は見られる
- 好感度上昇を視覚的に認識できる
- `次もエマと続けたい` 感情が残る

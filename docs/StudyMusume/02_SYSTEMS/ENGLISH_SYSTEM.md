# English System

## Summary

- `study-musume` は `推しヒロインが伴走してくれる英語学習恋愛ゲーム`
- プレイヤーは毎回 `誰と勉強するか` を選び、そのキャラとの好感度を上げていく
- 中心ループは `授業を受ける -> 指定ヒロインのクイズに答える -> 好感度が上がる -> 個別会話が開く`

## Core Loop

1. Home で今日の推しヒロインとおすすめ学習を確認する
2. `文法授業 / 英単語 / 英文添削 / 復習` のどれかを始める
3. 学習中にヒロインの短い反応や励ましが入る
4. セッション終端で `指定ヒロインの確認クイズ` または `添削コメント` が出る
5. 結果に応じて `理解度`, `継続`, `そのヒロインの好感度` が上がる
6. 一定条件で `個別会話`, `放課後イベント`, `思い出` が解放される

## Learning Modes

### 文法授業

- `授業会話 -> 確認問題 -> リザルト`
- 授業本編は既存の `grammar-lesson-rules` に沿って作る
- 授業の最後に指定ヒロインが `1〜3問の確認クイズ` を出す
- 正解で `lesson理解度 + affection` を獲得する

### 英単語クイズ

- 指定ヒロインが短い勉強相手になる
- 5問前後の短いセッションで回せる
- 出題テーマより `ヒロインごとの反応差分` で個性を出す

### 英文添削

- プレイヤーが短い英文を書く
- 指定ヒロインが `ここは自然`, `ここはこの形がいい` とコメントする
- `書く -> 直す -> 褒められる` の流れを重視する
- 再提出できると学習体験と好感度上昇をつなげやすい

### 復習

- 忘却対策として必要だが、見せ方は事務的にしない
- `この前のところ、もう一回やってみようか` のようにヒロインが声をかける
- 復習成功時は個別リアクションを返す

## MVP Scope

- 最初に完成させる学習モードは `文法授業`, `英単語クイズ`, `英文添削` の3本
- 会話練習モードは後回しでもよい
- 学習要素が恋愛のおまけにならないことを優先する

# Relationship System

## Player Promise

- 英語を勉強すると、成績だけでなく `推しとの距離` が縮まる
- 同じ勉強でも、誰を選ぶかで `教え方`, `反応`, `褒め方`, `解放イベント` が変わる
- 毎日の学習が `義務` ではなく `その子に会う理由` になる

## 指定ヒロイン制

- Home で `今いっしょに勉強するヒロイン` を1人指定する
- 指定ヒロインはホーム立ち絵、授業後クイズ、単語出題、添削コメントの担当になる
- 他ヒロインも授業シーンには出るが、報酬の中心は指定ヒロインに寄せる

## 好感度システム

### 基本

- 好感度は `ヒロインごとに個別管理`
- 当面は `好感度` を主軸にして、複雑なパラメータは増やしすぎない
- 追加するとしても後から `信頼` や `思い出数` を足す形にする

### 上がる行動

- 文法授業後の確認クイズ正解
- 英単語クイズの完走
- 英文添削の再提出成功
- 復習の継続
- そのヒロインの得意ジャンルを一緒に進める

### 上げ方のルール

- 不正解だけで大きく下げない
- `頑張って続けた` ことも評価する
- 周回より日常の積み上がりが感じられる増え方にする
- 一気に稼ぐより `毎日少しずつ会う` 方が強い設計にする

## 好感度段階の目安

- `Lv1`: 顔見知り、軽い応援
- `Lv2`: 授業後の雑談解放
- `Lv3`: 放課後の個別勉強イベント解放
- `Lv4`: 本命候補として意識され始める
- `Lv5`: 個別ルート入口

## 約束と個別ルート

- 放課後イベントは `次に会う理由` を作るための導線として使う
- `promiseState` を使って、会いに行く前の期待を Home で見せる
- ルート解放は `好感度だけ` にするか、`学習回数` や `特定モード達成` を混ぜるかを今後決める

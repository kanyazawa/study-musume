# Game Systems

## Current Direction

- ジャンルは `学習恋愛シミュレーション`
- `ウマ娘` から取るのは育成システムではなく `UIの気持ちよさ / リザルト演出 / ホームの見せ方`
- `アマガミ` から取るのは `日常の積み重ねで距離が縮まる空気`
- 学習は `数値育成の作業` ではなく `ヒロインと一緒に進める日常行動`

## MVP Rules

- MVP の看板ヒロインは `高瀬エマ` 1人に固定する
- Home は `エマが待っている放課後の学習ホーム` として見せる
- 文法授業は `放課後の学習サポートシーン`
- 授業の最後に `エマが確認クイズを出す`
- 正解すると `理解度` と `エマの好感度` が上がる
- `英単語クイズ` と `英文添削` も当面はエマが伴走する
- ご褒美は `好感度上昇 / 個別会話 / 表情差分 / 思い出解放` を中心にする

## Existing Systems To Keep

- `review` は引き続き重要導線にする
- `review優先表示` は Home で維持する
- `忘却率` は学習の必要性を作るため残す
- ただしプレイヤー体験の中心は `復習タスク消化` より `エマと続けること`

## 最初に決めておくべき事項

### 1. プレイヤーに毎日何をさせたいか

- 基本導線を `Homeでおすすめを見る -> 学習する -> リアクションを見る -> 次の約束や会話が気になる` に固定する
- `復習を片づけるゲーム` ではなく `エマに会うために勉強するゲーム` を主軸にする

### 2. Home の主役を何にするか

- 主役を `エマ`, `今日のおすすめ学習`, `次の予定` の3つに絞る
- `学習アプリのメニュー画面` ではなく `恋愛ゲームのホーム画面`

### 3. エマ固定でどこまで通すか

- 当面は `selectedHeroineId` をMVPの主役にしない
- 担当範囲を `ホーム立ち絵`, `授業後クイズ`, `単語リアクション`, `添削コメント`, `イベント予告` まで通す

### 4. 好感度がどの行動で上がるか

- `授業後クイズ正解`, `復習継続`, `英単語完走`, `添削再提出`, `イベント達成`
- 不正解で下げるか下げないかを先に決める

### 5. 保存データで何を持つか

- `emmaAffection`
- `routeState`
- `promiseState`
- `storyProgressSummary` に必要な日付や時間帯

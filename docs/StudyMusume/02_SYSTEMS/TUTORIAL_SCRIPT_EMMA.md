# Emma Tutorial Script

## 目的

- `高瀬エマ` を看板にした単独ヒロイン案で、Home 文言と初回チュートリアルの空気を固める
- 実装前に `最初の5分で何を見せるか` を具体化する

## Home 文言案

### 初回ホームの主見出し

- `放課後、エマが待っている`
- 代替案: `今日はエマとここから始める`

### 上部サブ文言

- `英語を続けるほど、彼女との距離が近づく`
- 代替案: `今日の弱点、エマと一緒に埋めよう`

### エマの一言

- 初回: `今日は長くやらなくていい。まず一個だけ、一緒に見よ`
- 基礎復習導線: `難しい単元の前に、土台だけ揃えよ`
- 再開時: `来ると思ってた。続き、やろうか`

### メインボタン文言

- `文法をはじめる`
- `5分だけ進める`
- `エマと確認する`

初回は `文法をはじめる` を第一候補にする。

### 補助文言

- `あとで進み方は変えられる`
- `今日はチュートリアルだから、短く終わる`

## 画面別の空気

### 1. タイトル後の導入

- モノローグ:
  - `放課後の教室。`
  - `英語は少し苦手だけど、あの子と一緒なら、もう少し続けられる気がした。`

### 2. 初回ホーム

- エマ:
  - `今日はここ、先に揃えよ。`
  - `難しいところに行く前に、土台が見えてたほうが楽だから。`

### 3. 学習中

- 進行中の短い差し込み:
  - `うん、その形で合ってる`
  - `今のところ、ちゃんと追えてる`
  - `焦らなくていい。一個ずつ見よう`

### 4. クイズ前

- エマ:
  - `じゃあ最後に一問だけ。`
  - `入ったか、見せて`

### 5. 正解時

- エマ:
  - `ちゃんと分かってる。いいね`
  - `前より、迷わなくなってる`

### 6. 不正解時

- エマ:
  - `大丈夫。今ので、どこが曖昧か分かった`
  - `ヒント出すから、もう一回だけやってみよ`

### 7. リザルト後

- エマ:
  - `今日のぶん、ちゃんと進んだ`
  - `もし明日も来るなら、続きを一緒に見ようか`

## 初回チュートリアル台本

### Scene 1: 放課後の導入

- 地の文:
  - `放課後の教室は、昼より少しだけ静かだった。`
  - `英語の課題を前に止まっていると、向かいの席から声がした。`
- エマ:
  - `まだ残ってたんだ`
  - `英語、詰まってる?`
- 主人公:
  - `ちょっとだけ`
- エマ:
  - `じゃあ今日は、一個だけ一緒に見よ`

### Scene 2: Home 着地

- エマ:
  - `長くやる必要はないよ`
  - `まずはここ。今日のぶんだけ`
- UI:
  - 立ち絵中央
  - メインボタン `文法をはじめる`
  - 補助文言 `今日は短く終わる`

### Scene 3: 短縮文法授業

- 学習テーマ例: `be動詞`
- エマ:
  - `難しい単元をやる前に、ここだけ揃えよ`
  - `基礎に戻るの、遠回りじゃないから`
- 進行中差し込み:
  - `そう、その形`
  - `今の理解で十分進められる`

### Scene 4: 確認クイズ

- エマ:
  - `じゃあ最後に一問だけ`
  - `焦らなくていいから、今のままで答えて`
- プレイヤー回答
- 正解時:
  - `うん、入ってる`
- 不正解時:
  - `大丈夫。主語と形だけ見直そ`
  - 再挑戦後:
    - `そう、それでいい`

### Scene 5: リザルト

- UI 表示:
  - `理解度アップ`
  - `好感度アップ`
  - 小さなハート演出
- エマ:
  - `ちゃんと進んでる`
  - `続ければ、もっと楽になるよ`

### Scene 6: 次の約束予告

- エマ:
  - `もし明日も来るなら、次はこの続き見よ`
  - `待ってる、は少し変かな`
  - `でも、多分来ると思ってる`
- 地の文:
  - `そう言って少しだけ目を逸らした彼女の顔が、さっきより近く感じた。`

### Scene 7: 通常ホームへ戻る

- Home 見出し:
  - `次のおすすめ: 文法の続き`
- エマの一言:
  - `明日も同じ時間なら、続き見れる`
- 小さな予告:
  - `次の会話まで あと1回`

## 実装時の必須要素

- 初回は `文法をはじめる` 以外を目立たせない
- クイズは1問だけ
- 不正解でも必ずフォローを入れる
- 好感度上昇はリザルト内で見せる
- 最後に `また会える理由` を1つ残す

## 完了条件

- プレイヤーが `エマと一緒に進めている` 感覚を持てる
- 英語学習の順番が固定授業ではなく `弱点補強` だと自然に伝わる
- 初回の終わりに `また来たい` と思える

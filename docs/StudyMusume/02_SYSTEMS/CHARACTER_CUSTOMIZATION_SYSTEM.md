# Character Customization System

## 結論

- `Aimy みたいなフルキャラデザ` は初期MVPではやらない
- `高瀬エマ` のキャラ性は固定したまま、`衣装 / 背景 / アクセ` を軽く切り替えられる方向で進める
- 目的は `別人を作ること` ではなく、`自分のエマ感` と `ごほうび感` を強めること

## この方針にする理由

- `study-musume` の主役は `エマとの学習継続体験` であり、ゼロから別キャラを作る遊びではない
- フルキャラメイクは `工数`, `アセット数`, `保存設計`, `UI複雑化` の負担が大きい
- いまの実装にはすでに `equippedSkin / equippedBackground / equippedAccessories` の受け皿がある
- 先に軽量カスタムを入れるほうが、`学習 -> 報酬 -> 愛着` のループを作りやすい

## プレイヤーに約束する体験

- 勉強を続けるほど、エマの見た目や空気を少しずつ自分好みにできる
- ただし `高瀬エマらしさ` は崩さない
- カスタムは `恋愛ゲームの没入感を強める補助` であって、主役そのものではない

## やること / やらないこと

### やること

- 衣装の切り替え
- 背景の切り替え
- アクセサリーの切り替え
- 解放済みアイテムを `CharacterInteraction` で選ぶ
- 好感度やガチャ報酬とつなぐ

### やらないこと

- 顔パーツの個別編集
- 体型, 身長, 輪郭, 目鼻口のスライダー調整
- プレイヤーが `別ヒロインを新規生成する` 機能
- 立ち絵の印象が別作品レベルで変わる大改造

## MVP仕様

### 1. 変更できる項目

- `衣装`
  - 既定制服
  - 私服
  - 季節差分 or 放課後用の軽衣装を1つ
- `背景`
  - 教室
  - 図書室
  - 夕方の通学路 or 放課後スポット
- `アクセ`
  - 髪留め
  - 小さなチャーム
  - 勉強小物

### 2. 変更しない項目

- 顔の骨格
- 髪色
- キャラの年齢感
- 声
- 基本性格

### 3. 見せ方

- カスタマイズ画面は `見た目を整える` 程度の軽さにする
- 一覧から `持っているものを選ぶだけ` に寄せる
- 初期は `試着UI` や `細かいレイヤー編集` まで作らない

## 解放導線

### 好感度で解放

- `関係が深まったごほうび` として私服や特別背景を解放する
- 目安:
  - Lv3: 図書室背景
  - Lv5: 私服
  - Lv7: 思い出背景 or 特別アクセ

### ガチャで解放

- ガチャは `キャラを引く場` ではなく、`エマとの時間を増やす報酬箱` として使う
- 軸は `衣装 / 背景 / アクセ / ボイス / 思い出`
- レア報酬は `ホームで変化が目に見えるもの` を優先する

### イベントで解放

- 季節イベントや節目会話で `限定アクセ` を渡せるようにする
- これにより課金やガチャだけに依存せず、継続報酬としても回せる

## エマ固定との両立ルール

- `高瀬エマ` という名前, 性格, 声, 立ち位置は固定
- 変えるのは `その日の装い` と `一緒にいる空気`
- シルエット, 顔立ち, 色設計は `TAKASE_EMMA.md` と `ART_STYLE.md` を崩さない

## アート運用ルール

- 1着ごとに別人に見えないことを最優先にする
- `上品`, `やわらかい`, `放課後感` を維持する
- アクセは主張しすぎず、会話UIより前に出すぎない
- 背景はキャラとUIを邪魔しない情報量に留める

## 実装に乗せるときの最小データ方針

- 既存の `inventory` に各カスタム報酬を入れる
- 装備状態は既存の下記を使う
  - `equippedSkin`
  - `equippedBackground`
  - `equippedAccessories`
- MVPでは `カラーコード単位の保存` や `顔パーツ単位の保存` は持たない

## UI方針

- Home では `今のエマ` がすぐ見えることを優先する
- `CharacterInteraction` の `カスタマイズ` を主導線にする
- 初期MVPでは新しい大型エディタ画面を増やさない
- カスタム結果は `Home / Tutorial / Interaction / Story` に順次反映する

## 最初に用意する解放セット

- 衣装
  - `default_uniform`
  - `casual_cardigan`
  - `seasonal_light`
- 背景
  - `classroom_default`
  - `library_evening`
  - `sunset_street`
- アクセ
  - `hairpin_star`
  - `study_charm`
  - `mini_ribbon`

## 後回しでよい拡張

- 髪型プリセット追加
- 表情テーマセット
- 部屋UIや机小物のカスタム
- Live2D専用の衣装差分
- プレイヤー名や呼び方と連動した演出差分

## 判断基準

- `自由度が高いか` より `エマへの愛着が増えるか`
- `編集機能が多いか` より `学習報酬としてうれしいか`
- `Aimyに近いか` より `study-musume の主軸を強めるか`

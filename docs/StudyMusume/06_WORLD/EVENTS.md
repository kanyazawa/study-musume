# Events

## 予定している種類

- 授業後の短い会話
- 放課後の個別勉強イベント
- 好感度段階ごとの節目イベント

## MVP の基本粒度

- 各ヒロインにまず `共通序盤イベント 3本 + ルート導入 1本` を用意する
- `共通序盤` はその子の魅力と感情変化の入口を見せる役割にする
- `ルート導入` は `この子が自分を特別に見始めた` と分かる節目にする
- 1イベントでやることは1つに絞る

## 共通序盤イベントの役割

### 1本目

- 第一印象と `この子の空気` を伝える
- 学習導線の中で自然に会える内容にする

### 2本目

- 性格の奥にあるやさしさや怖さを少し見せる
- プレイヤーが `また会いたい理由` を作る

### 3本目

- 明確な態度変化を1回見せる
- `疑う -> 認める` など、感情変化が進んだと感じさせる

## ルート導入イベントの役割

- 恋愛としての特別感が初めて見える場面にする
- 約束、帰り道、居残り、夜の振り返りなど `二人感` が出やすい状況を使う
- ここから先は他ヒロインと違う温度になる、と分かる設計にする

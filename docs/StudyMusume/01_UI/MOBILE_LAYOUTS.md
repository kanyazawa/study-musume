# Mobile Layouts

`study-musume` の `英語学習 x 複数ヒロイン` 導線を、モバイル前提の簡易ワイヤーとして整理する。
デザインを盛る前に、まず `何をどこに置くか` を固定するためのメモ。

## 1. Home

最優先で作る画面。
既存の Home を土台にしつつ、`推しヒロイン選択` と `学習開始導線` を主役にする。

### 置くもの

- 上部: 日付、継続、review優先表示
- 中央: 指定ヒロイン立ち絵
- 立ち絵周辺: 一言セリフ、次の好感度イベント予告
- 下部メイン: `文法授業`, `英単語`, `英文添削` の大ボタン
- 補助導線: `ヒロイン変更`, `思い出`, `イベント`, `復習`

### ワイヤー

```text
+--------------------------------------------------+
| DAY / STREAK / REVIEW                            |
| 次のおすすめ: 文法授業                          |
+--------------------------------------------------+
|                                                  |
|              [ 指定ヒロイン立ち絵 ]               |
|        「今日はこの文法、いっしょにやろう？」     |
|       好感度 Lv3 / 次イベントまで あと 12        |
|                                                  |
+--------------------------------------------------+
| [ 文法授業 START ]                               |
| [ 英単語 QUIZ ]                                  |
| [ 英文添削 CHECK ]                               |
+--------------------------------------------------+
| [ヒロイン変更] [思い出] [復習] [イベント]         |
+--------------------------------------------------+
```

## 2. Heroine Select

一覧より `推しを決める画面` に寄せる。

### 置くもの

- ヒロイン4人の並び
- 現在の好感度
- 一言フック
- 次に解放される要素
- `この子と勉強する` ボタン

## 2.5 Tutorial Flow

- `推し選択 -> Home -> 文法授業 -> 確認クイズ -> リザルト -> 次の約束予告`
- 初回は `文法授業 START` 以外を目立たせすぎない
- リザルト内で `好感度上昇` を見せる
- `あとで変更できる` 表示で最初の選択圧を下げる

## 3. Grammar Lesson

授業本編は既存フォーマットを使い、新規で足すのは `最後のヒロイン確認クイズ` と `結果演出`。

## 4. Vocabulary Quiz

- 出題中のヒロイン
- 問題文
- 3択または入力
- 連続正解演出
- セッション結果

## 5. Writing Correction

- 英文入力欄
- ヒロインのコメント
- 修正版再提出ボタン
- 完了時の褒めリアクション

## 実装優先順

1. Home に `指定ヒロイン枠` を入れる
2. Home に `文法授業 / 英単語 / 英文添削` の主導線を入れる
3. Heroine Select を作る
4. Grammar Lesson 終了時にヒロイン確認クイズを差し込む
5. Result 画面で `好感度上昇` を見せる

# UI Prompts

UI 作業を AI に頼むときのコピペ用テンプレ。
見た目だけ直したいとき、ワイヤーだけ出したいとき、Home に寄せたいときに使う。

## UI Only Prompt

UI のみ改善してください。
ロジック変更禁止。

## UI Wireframe Prompt

`study-musume` 用の画面ワイヤーを作ってください。

条件:
- 1ファイルだけで出してください
- React + Vite 前提で考えてください
- Next.js 前提にしないでください
- shadcn/ui や外部ライブラリは使わないでください
- レイアウトと構造を優先してください
- 装飾は最小限にしてください
- まずはコピーしやすい簡単な JSX にしてください

## Existing Screen Edit Prompt

既存画面をベースに編集してください。

条件:
- 指定ファイルだけ触ってください
- 既存 class 名は変えないでください
- JSX 構造はできるだけ維持してください
- 大きなリファクタはしないでください
- まず既存の見た目を尊重してください

## Home-Style UI Prompt

この画面は `学習アプリ一覧` ではなく `study-musume のホーム画面の兄弟画面` として考えてください。

条件:
- 既存 Home の空気感を優先してください
- 白背景の SaaS 風カード一覧にしないでください
- 主要アクションを主役にしてください
- 情報は詰め込みすぎないでください
- 可能なら既存のホーム用ボタンや構成を流用する前提で考えてください

# SNS Strategy

## 目的

- `study-musume` の世界観と学習モチベーションを伝える
- キャラ性と日常感を前面に出す

## 方針

- 学習アプリ告知より `推しと勉強する体験` を見せる
- UI だけでなくキャラの反応や空気感も出す

## AI運用方針

- SNS 運用は `完全自動投稿` ではなく、`AI半自動 + 人の最終承認` を基本にする
- AI は `ネタ出し / 投稿文ドラフト / 動画案 / ハッシュタグ整理` を担当する
- 投稿ボタンを押す前に、人が `誤字 / 誇大表現 / 世界観のズレ / 炎上リスク` を確認する
- `開発報告` だけでなく、`エマとの日常`, `学習の小さな達成感`, `放課後感` を柱にする

## 役割分担

- 企画AI:
  - `PROJECT_STATUS.md` と `TODO.md` から今週のネタを拾う
  - `05_SNS/CONTENT_PLAN.md` に週ネタを並べる
- 投稿文AI:
  - `X_POSTS.md` に短文ドラフトを書く
  - 言い回しを `やさしい / 放課後 / 少し恋愛寄り` に寄せる
- 動画案AI:
  - `TIKTOK_IDEAS.md` に短尺動画の構成案を書く
  - スクショ候補や見せる順番も出す
- レビューAI:
  - 投稿前に文の危うさ、意味のズレ、売り文句の弱さを確認する
- 人:
  - 最終承認と投稿

## 投稿の柱

- `エマとの放課後感`
- `勉強を見守られる体験`
- `Home / Tutorial / Gacha` など開発の進捗
- `英語学習の小ネタ` とゲーム体験の接続

## NG寄りの運用

- 毎回 `アプリを作っています` だけの開発日誌にする
- 機能名だけ並べて感情や空気感がない投稿にする
- AI が作った文を未確認でそのまま自動投稿する

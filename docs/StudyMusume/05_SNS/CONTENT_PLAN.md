## 週次フロー

1. `PROJECT_STATUS.md` と `TODO.md` から今週の進捗を拾う
2. 今週の投稿柱を `3-5本` に絞る
3. `X_POSTS.md` に短文ドラフトを書く
4. `TIKTOK_IDEAS.md` に短尺動画ネタを書く
5. レビューAIで危ない表現や弱い表現を見直す
6. 人が最終承認して投稿する

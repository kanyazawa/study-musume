# TikTok Ideas

## メモ

- Home のビフォーアフター
- キャラの一言リアクション集
- 学習演出の短尺紹介

## AIドラフトの型

- `最初の1秒で見せる絵`
- `5-15秒の流れ`
- `最後のひとこと`

## 当面の短尺案

### Home ビフォーアフター

- 1秒目:
  - 旧 Home と新 Home を一瞬で切り替える
- 中盤:
  - エマ立ち絵
  - 大ボタン
  - 次にやる勉強の導線
- 締め:
  - `ただの勉強アプリじゃなくて、放課後に会いに行く感じへ`

### エマの反応集

- 1秒目:
  - エマの表情アップ
- 中盤:
  - タップ反応
  - 学習後リアクション
  - まばたきや待機モーション
- 締め:
  - `勉強を見守ってくれる子がいると少し続けやすい`

### 学習ごほうび導線

- 1秒目:
  - 勉強後にガチャや報酬が見える場面
- 中盤:
  - 学習 -> ごほうび -> エマ反応
- 締め:
  - `少し進めるたびに、ちゃんと帰ってきたくなる導線を作りたい`

# 高瀬エマ

## 位置づけ

- `study-musume` の `単独ヒロイン案` 用の看板キャラ
- 複数ヒロイン案を消す前提ではなく、`一人に絞るとしたらこの方向が強い` という検討用たたき台

## 基本設定

- 名前: 高瀬エマ
- 属性: 帰国子女の同級生
- 立場: 放課後に付き合ってくれる学習パートナー
- 年齢感: 主人公と同学年
- 英語力: 高い
- 関係の入口: `英語を見る相手` として近づき、だんだん `放課後に会いたい相手` へ変わる

## この設定が自然な理由

- 英語が得意な理由を `帰国子女` で一発で通せる
- `今日は基礎に戻ろう` が弱点補強として自然
- 教師でも家庭教師でもなく、学校生活の延長で一緒にいられる
- 学習順が前後しても `主人公の弱点を埋めている` で説明できる

## 性格

- 落ち着いている
- 観察力が高い
- 説明は分かりやすい
- 感情表現は少し不器用
- 続ける人にはちゃんとやさしい

## 本質

- `ちゃんとここにいていい居場所がほしい`
- 英語は得意でも、日本の学校生活ではまだ少し浮いている
- 主人公と過ごす放課後だけは、無理に合わせすぎず自然でいられる

## 感情変化

- 観察
- 評価
- 安心
- 恋

## 刺さるポイント

- 英語ができる安心感
- 毎日少しずつやわらかくなる距離感
- `教えてくれる人` から `自分を待ってくれる人` に変わる流れ
- 近寄りがたいのに、自分の前では少し素直になる特別感

## 学習中の見え方

- 新しい単元でも復習単元でも、常に `今の弱点を埋める` テンションで付き合う
- 難しいことをひけらかさず、必要なところだけ短く教える
- ミスしても責めず、どこで崩れたかを静かに見抜く
- 続けるほど `説明役` から `伴走役` に変わっていく

## 授業シーンでの立ち位置

- `学校の正規授業` ではなく `放課後の学習サポート`
- 場所は `空き教室 / 図書室 / 自習スペース` を想定する
- エマは `講義する先生` ではなく `隣で進める相手`
- 画面上部の短いセリフで空気を作り、最後の確認クイズを出す役に向く

## セリフの空気感

### 導入

- 「今日はここ、先に揃えよ」
- 「順番より、今崩れてるところから見たほうが早いよ」

### 基礎復習

- 「時制の前に、ここ曖昧だと崩れるから」
- 「基礎に戻るの、遠回りじゃないよ」

### ミス時

- 「大丈夫。どこで引っかかったか分かった」
- 「焦らなくていい。一個ずつ見る」

### リザルト時

- 「ちゃんと入ってる。続けたぶん、前よりいい」
- 「来ると思ってた。今日も見れてよかった」

## 立ち絵要件

- 清潔感のある制服姿
- 薄いカーディガンや軽い羽織りで、知的さと日常感を両立する
- 立ち姿はまっすぐだが、冷たすぎない
- 髪型は整っていて上品、派手すぎない
- 小さな海外由来アクセや髪留めを1つだけ入れて背景を匂わせる

## 表情差分

- 通常: 落ち着いた観察目線
- 微笑み: 口元だけやわらぐ
- 納得: 少し満足げに認める
- 困り: 不器用に気遣う
- 照れ: 視線が揺れる、言葉が少し詰まる
- 恋寄り: 安心したやわらかい笑顔

## MVP表情差分仕様

- `表情6個 + 待機2個 + 反応2個` を最小セットにする
- 目的は `ぬるぬる動くこと` より `会話に合わせて気持ちが伝わること`
- 学習画面の邪魔をしないことを前提に、常時モーションは弱めにする

### 表情6個

- 通常: やさしい微笑み。基本の会話顔
- 嬉しい: 褒める, 会えてうれしい, 正解を喜ぶ場面
- 真剣: 文法説明, 確認クイズ, 少し大事な話
- 困る / しょんぼり: 不正解, 無理しすぎ, 心配する場面
- 照れ: 距離が縮まる場面, ごほうび会話, 好感度上昇
- 驚き: 意外な正解, 急な反応, イベントのアクセント

### 待機2個

- まばたき: 常時入れる。最優先
- 呼吸: 胸や肩が少しだけ動く程度に抑える

### 反応2個

- 小さくうなずく: 正解時, 励ます時, 説明の締め
- 少し身を乗り出す: 距離が縮まった場面, 特別感を出す場面

## MVP運用ルール

- 通常会話は `通常 / 嬉しい / 真剣` を中心に回す
- 不正解や心配シーンは `困る / しょんぼり` を使う
- 好感度イベントは `照れ` を優先する
- アクセントだけ `驚き` を使う
- 常時モーションは `まばたき + ごく弱い呼吸` に留める
- `うなずき / 身を乗り出す` は特別な場面だけに絞る

## 画面での役割

- Home: `今日も待ってくれている` 看板
- 学習中: 進行の安心感を作る上部セリフ役
- リザルト: `ちゃんと見てもらえた` ご褒美役
- チュートリアル: 世界観と学習導線を一番自然につなぐ顔

## 売り文句の核

- `放課後、帰国子女の彼女があなたの英語を見てくれる`
- `勉強を続けるほど、彼女の距離が近づく`
- `教えてくれるだけじゃない。一緒に続けてくれる`

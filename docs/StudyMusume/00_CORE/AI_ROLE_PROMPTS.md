# AI Role Prompts

複数AIへ役割別に投げるためのコピペ用テンプレ。
長い説明を毎回書かずに、担当だけ切って依頼したいときに使う。

## 統合担当 Prompt

この repo の統合担当として動いてください。

やってほしいこと:
- 現在地を整理する
- 仕様と実装のズレを見つける
- 他AIの出力をまとめる
- 必要なら `PROJECT_STATUS.md` と `TODO.md` を更新する

制約:
- いきなり大きく実装しなくてよい
- まず担当範囲と次の一手を整理する

## 実装担当 Prompt

この作業では実装担当として動いてください。

やってほしいこと:
- 指定ファイルだけを中心に実装する
- 役割範囲の外には広げすぎない
- build を壊さない

制約:
- 同時に別AIも作業している前提です
- 指定された担当外のファイルにはなるべく触れないでください
- 大きな構造変更より、目的達成に必要な変更を優先してください

## 調査担当 Prompt

この作業では調査担当として動いてください。

実装はしないでください。
原因分析のみしてください。

確認項目:
- JSX閉じ忘れ
- import漏れ
- undefined
- class名不一致
- 状態の流れの不整合

返し方:
- 原因候補を列挙する
- 怪しいファイルと行付近を示す
- 修正するなら何を直すべきかだけ短く添える

## レビュー担当 Prompt

この作業ではレビュー担当として動いてください。

やってほしいこと:
- 実装はせず、差分レビューを優先する
- バグ、仕様ズレ、見落とし、テスト不足を探す
- 問題がなければ `大きな問題なし` と明示する

見てほしい観点:
- JSX の閉じ忘れ
- import 漏れ
- `undefined` の可能性
- class 名と CSS 側の不一致
- state / props の流れの破綻
- 既存仕様とのズレ

返し方:
- findings を先に出す
- 怪しいファイルと行付近を書く
- 直し方は短く添える
- 実装そのものはしない

## UI 発想担当 Prompt

この作業では UI 発想担当として動いてください。

やってほしいこと:
- まずレイアウト案を出す
- 実装しやすい形を優先する
- `study-musume` の Home と兄弟画面に見える案を優先する

制約:
- 学習アプリ一覧画面にしない
- 白背景 SaaS 風カード一覧にしない
- 1つの強い案を先に出す

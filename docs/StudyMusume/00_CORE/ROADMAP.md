# Roadmap

## Phase 1: エマMVPの芯を固める

1. Home で `高瀬エマ` を看板として見せる
2. 初回チュートリアルを `Home -> 学習 -> クイズ -> リザルト` で通す
3. Home に `文法授業 / 英単語 / 英文添削` の主導線を置く
4. Home のおすすめ表示を `review + エマ優先` に調整する

## Phase 2: エマ伴走を学習に通す

1. 文法授業の最後に `エマ確認クイズ` を差し込む
2. 正解時に `好感度上昇表示` を入れる
3. 英単語クイズを `エマ伴走体験` に寄せる
4. 英文添削にエマコメント導線を付ける

## Phase 3: エマとの関係進行を見える形にする

1. 好感度しきい値で個別会話を解放する
2. 放課後イベントや約束の導線を Home と Character 側でつなぐ
3. 中盤以降のエマ固有イベントを増やす

## 後回しにすること

- `Heroine Select` と複数ヒロイン導入
- `信頼` など好感度以外の関係値
- 会話練習モードの初期MVP投入
- 複雑な育成パラメータ
- デート消化中心の設計

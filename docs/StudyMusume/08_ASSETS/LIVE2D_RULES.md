# Live2D Rules

## 方針

- Home で自然に置ける立ち方を優先
- 過剰なモーションより `触ったときの反応` を大事にする
- 既存の Live2D 関連 docs を必要に応じて参照する

## MVPモーション方針

- `表情変化を優先`, `常時モーションは控えめ` を基本にする
- 学習ゲームなので、立ち絵は主役でも `集中を邪魔しない` 強さに抑える
- 常に大きく揺れる動きや、セリフのたびに派手に動く演出は避ける

## 最小セット

- 表情差分: `通常 / 嬉しい / 真剣 / 困る / 照れ / 驚き`
- 待機: `まばたき / ごく弱い呼吸`
- 反応: `小さくうなずく / 少し身を乗り出す`

## 優先順位

1. `セリフごとの表情変化`
2. `小さい待機モーション`
3. `特別場面だけの反応モーション`

## シーン別の使い方

- 通常時: `まばたき + 呼吸`
- 会話中: セリフに合わせて表情だけ切り替える
- 正解時 / 好感度上昇 / 特別な一言: `うなずき` か `身を乗り出す` を足す

## 判断基準

`Live2Dでよく動く` より `会話に合わせて気持ちが伝わる` ことを優先する。

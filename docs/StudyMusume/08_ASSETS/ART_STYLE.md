# Art Style

## 方針

- 学校と日常の空気を優先
- 派手すぎるファンタジーより、親しみやすい恋愛ゲーム寄り
- UI と立ち絵の温度差を出しすぎない

## 全体の統一方針

- `やわらかいアニメ調` を全体の基準にする
- `明るめ`, `親しみやすい`, `少し上品` を共通の印象にする
- キャラ, 背景, 小物, UI アセットで `同じ作品の住人と空気` に見えることを優先する
- 1枚ごとの派手さより `ゲーム全体で並べたときの統一感` を優先する

## 基準文

`やわらかいアニメ調で統一。明るめで親しみやすく、少し上品。線は細め〜中細、影は浅め、彩度は中程度。キャラ・背景・小物すべてで、やさしい空気感と見やすさを優先する。`

## 絵柄ルール

### 1. 顔の描き方

- 目の大きさ, 鼻口の省略具合, 輪郭の丸さをキャラ間でそろえる
- `別作品感` が出やすいので、顔だけリアル寄りになる崩れ方を避ける
- エマは `知的で優しい`, `落ち着いたお姉さん` が伝わる柔らかいアニメ顔を基準にする

### 2. 線

- 線画は `細め〜中細`
- 強い主線やギラついた線の強弱は避ける
- 背景だけ絵本風 / キャラだけ厚い主線、のような分離を作らない

### 3. 塗り

- `やわらかいアニメ塗り` を基本にする
- 影は `1〜2段`, 浅めで十分
- 強い厚塗り, 過剰な反射, 極端な金属感は避ける

### 4. 色

- `明るめ + 少し暖かい` 配色を基本にする
- 彩度は中程度にそろえ、極端なネオン感は出しすぎない
- 真っ黒や重い寒色を広く使いすぎず、安心感を崩さない

### 5. 頭身と情報量

- 頭身, 手足の長さ, 服の描き込み量をキャラ間で大きくずらさない
- 1人だけリアル等身 / 1枚だけ装飾過多、のような浮きを避ける

### 6. 空気感

- 作品全体を `やさしい`, `安心感がある`, `学習しやすい` 方向にそろえる
- 劇的さや強い刺激より、`また開きたくなる親しみやすさ` を優先する

## 背景ルール

- 背景もキャラと同じく `やわらかいアニメ調` にそろえる
- 描き込みすぎず、立ち絵や会話UIを邪魔しない情報量にする
- コントラストは抑えめにして、キャラが前に出るようにする
- 教室, 廊下, 放課後の街など日常背景は `少し暖かい光` を感じる方向に寄せる

## エマの立ち絵方針

- エマは `アニメ寄り` を基本にする
- ただし `萌え全開` より `会話ゲーム向けの柔らかいアニメ立ち絵` に寄せる
- 目立ちすぎる派手さより、`上品さ`, `優しさ`, `見やすさ` を優先する
- 目安は `アニメ調 7割 + 少し自然寄り 3割`

## 発注 / 生成用の短い指示文

`study-musume 全体を、やわらかく上品なアニメ調で統一してください。キャラクター、背景、小物すべてで、明るめの配色、浅めの影、細め〜中細の線、親しみやすく見やすい空気感を共通化してください。背景は描き込みすぎず、キャラを邪魔しない情報量とコントラストにしてください。全体として、学習ゲームに合う安心感のある世界観を重視してください。`

## 最短の判断基準

`その絵が良いか` より `study-musume の住人に見えるか` を優先する。

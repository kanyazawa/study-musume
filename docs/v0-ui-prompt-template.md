# v0 UI Prompt Template

`study-musume` で v0 を使うときの定番プロンプトです。

## 基本

```txt
[画面名] のUIを作ってください。

重要:
新しいプロジェクト一式は作らないでください。
ファイル分割はしないでください。
1ファイル完結で、コピペできる最小コードだけ出してください。

要件:
- デザインは不要
- 配置だけ作る
- 枠組みだけでよい
- 画面に必要な要素は最低限だけ置く
- ダミーテキストは最小限でよい

不要なもの:
- components / hooks / lib / styles への分割
- 外部ライブラリ
- 状態管理
- アニメーション
- アイコン
- 作り込んだ装飾
- ファイルツリー
- 長い説明

出力ルール:
- 1ファイルだけ出す
- 余計なコードは入れない
- シンプルなマークアップにする
- そのままコピペできる形にする
- 完成UIではなくワイヤーフレームとして出す
```

不要なもの:

## HTMLで骨組みだけほしいとき

```txt
ミッション画面の枠組みを、HTML1ファイルだけで出してください。

重要:
- React / Next.js は使わない
- プロジェクト一式は作らない
- ファイル分割しない
- HTMLだけで完結させる
- 必要ならCSSは同じファイル内に最小限だけ書く
- JavaScriptは使わない
- デザインは不要
- 配置だけ分かるワイヤーフレームにする
- 余計な説明は書かない
- コードだけ出す

必要な構成:
- 上部バナー枠
- キャラ表示枠
- タイトル・開催期間の情報枠
- タブ枠
- ミッション一覧枠
- 各ミッションの報酬枠
- 進捗バー枠
- 操作ボタン枠
- 下部ボタン枠

出力ルール:
- 単一のHTMLコードだけ出す
- そのままコピペできる形にする
- 完成デザインではなく骨組みだけにする
- div, section, button など基本タグ中心でシンプルにする
```

## 使い分け

- `まず構造だけ見たい` ときは HTML 版
- `そのまま React に貼る前提` なら JSX/TSX 版
- v0 の出力が大きすぎるときは、Codex に渡して 1 ファイルへ整理させる

## Codex に渡すとき

```txt
このv0の出力を study-musume の既存構成に合わせて整理して。
ファイル分割なし、最小構成で、コピペしやすい1ファイルにして。
見た目の作り込みは不要です。
```

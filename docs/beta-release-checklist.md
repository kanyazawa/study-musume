# Study Musume Beta 公開チェックリスト

最終更新: 2026-06-10

このメモは、`2026-06-10` 時点の `study-musume` を今週中に `β公開` するための最小チェックリストです。

対象は次の2つです。

- `Web β`
- `Android 内部テスト / クローズドテスト`

- [ ] 未完成導線は `見せない / 踏ませない`
- [ ] 公開対象を `β版` と明記する

- [x] `npm test` は通る
- [x] `npm run build` は通る
- [x] 主要ルートの smoke check は通る

## 3. 今週版の公開条件

- [ ] `npm test` が緑
- [ ] `npm run build` が成功
- [ ] `タイトル → ホーム → 学習 → 復習 → 保存復元` を1周できる
- [ ] 再起動後も保存データが残る
- [ ] 進行不能バグがない
- [ ] 公開しない機能の導線が閉じている

## 4. Web β の最短手順

1. `npm test`
2. `npm run build`
3. ホスティング先へ反映
4. 公開後に実機で `ホーム / 学習 / 復習 / 保存` を再確認
5. β版案内を掲載する

Web β の公開文言テンプレート:

```text
Study Musume β版を公開しました。
まだ調整中の機能があり、表示や保存まわりで不安定な箇所が残る可能性があります。
不具合や気になった点があればフィードバックをお願いします。
```

## 5. Android 内部テストの最短手順

1. `npm run android:release:prep`
2. `android/app/build.gradle` の `versionCode` を公開用に更新
3. `android/keystore.properties` がローカルにあることを確認
4. `npm run android:bundle:release`
5. 生成した AAB を `内部テスト` か `クローズドテスト` にアップロード
6. Android 実機で `ログイン / ホーム / 学習 / 復習 / 保存` を再確認

Android β の公開文言テンプレート:

```text
Study Musume のβテスト版です。
学習、復習、キャラクター交流を中心に遊べますが、一部機能は調整中です。
不具合や進行不能があればテスター向け連絡先までお願いします。
```

## 7. バージョン運用メモ

- `package.json` の現在値は `1.0.0`
- Android `versionName` の現在値は `1.0.0`
- Android `versionCode` の現在値は `2`
- Android `versionCode` はアップロードごとに必ず増やす

今週中の例:

- 初回内部テスト: `versionCode 2`
- 修正版再提出: `versionCode 3`

## 8. 署名ファイルの扱い

次は `ローカル専用` として扱うこと:

- `android/keystore.properties`
- `android/release-keystore.jks`
- `android/*.7z`

やってはいけないこと:

- Git に追加する
- チャットやスクリーンショットで値を共有する
- そのままバックアップファイルを配布する

もし外部共有した可能性があるなら:

1. 署名鍵を作り直す
2. `keystore.properties` を新しい値で入れ直す
3. 配布前に AAB を再生成する
